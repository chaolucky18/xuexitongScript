# 学习通视频与章节测验助手（Edge 控制台版）

这个版本不需要 Tampermonkey。DeepSeek API Key 输入到本地服务的窗口中，不会写入控制台脚本或保存到文件。

## 首次使用

1. **停用此前安装的学习通油猴脚本**，避免它与控制台版同时操作页面。
2. **先将 ZIP 全部解压到同一个文件夹**，不要直接从压缩包内运行文件。双击解压后文件夹里的 **`启动 DeepSeek 本地服务.cmd`**。在黑色窗口粘贴 DeepSeek API Key，按 Enter。输入过程不显示字符。窗口显示“本地服务已启动”后保持它打开。
3. 用记事本打开同目录的 **`xuexitong-console.js`**，按 **Ctrl+A、Ctrl+C** 复制完整文件。它是缩短缩进后的控制台复制版；不要从聊天窗口的代码预览中复制片段。
4. 在 Edge 中打开学习通课程播放页，按 F12 → Console，粘贴脚本，按 Enter。脚本会打开一个小的“学习通自动任务辅助窗口”；请保持这个窗口打开。它用于在“下一节”触发整页跳转后重新启动控制台脚本。随后可以关闭开发者工具，返回课程页。

每次关闭本地服务窗口后再次运行，都需要重新输入 API Key，并重新复制一次 `xuexitong-console.js`。本地服务每次启动都会更新脚本中的临时连接令牌。

如果服务退出，窗口会停在“请按任意键继续”。请查看上方的报错文字。`启动 DeepSeek 本地服务.cmd`、`deepseek-local.mjs`、`deepseek-request.mjs` 和 `xuexitong-console.js` 必须在同一文件夹内。

## 自动流程

- 视频页：使用页面默认播放速度，不设置倍速；视频结束后点击页面下方的“下一节”。
- 测验页：滚动题目区域、识别实际出现的单选、多选和判断题，调用 DeepSeek 判断并选择选项；核对题量后点击“提交”，处理学习通弹出的二次提交确认，等“本次成绩”或当前章节的完成标记出现后点击页面下方的“下一节”，进入新视频并开始下一轮任务。如果从已完成的测验页启动脚本，也会直接进入下一节。
- 服务关闭 DeepSeek 思考模式，并把单题输出限制在 512 tokens；若答案仍被截断，再以 1024 tokens 重试一次，避免思考过程消耗大量输出额度。
- 整套题一次请求，并使用简短提示词；输入题目内容不做截断。
- 视频会在播放前、以及恢复播放前主动设置静音。若页面播放器使用独立音频通道或重新创建了播放器，仍可能需要检查网站播放器本身的静音状态。
- 点击“下一节”后最多等待 120 秒确认新页签加载；测验提交按钮和题目分别最多等待 120 秒。提交后持续等待成绩页，不会因出分慢而提前停止；每 15 秒在控制台显示一次等待进度。刷新课程页可以停止脚本。
- 页面结构、题量、选项、接口或提交结果不符合预期时停止并在控制台显示原因。
- DeepSeek 请求使用较低的思考强度和更充足的输出额度。如果回答被截断或 JSON 为空，本地服务会自动重试一次；仍不完整时停止，不会拿残缺答案提交。

浏览器可能询问是否允许该课程页访问本地网络；此请求用于连接电脑上运行的本地服务。若被浏览器策略或页面策略阻止，控制台会显示连接错误，脚本不会继续自动答题。若 Edge 阻止了小辅助窗口，请允许 `mooc1.chaoxing.com` 打开弹出窗口后重新运行脚本；否则整页跳转后需要手动在新页面重新粘贴脚本。

题目和选项会发送至 DeepSeek API，调用可能产生费用，模型也可能答错。已在当前课程页确认题目识别、DeepSeek 调用、二次提交确认、100 分成绩页及“下一节”到新章节的跳转；整页跳转后的辅助窗口自动恢复经过模拟测试，尚未在真实课程页完成连续运行验证。首次使用请观察一次完整流程。

调试时可在控制台输入 `app.inspectQuiz()` 查看识别到的题目。关闭本地服务窗口即可停止 API 调用；刷新课程页可停止页面脚本。

如果页面顶部出现黄色的“已在调试程序中暂停”，请在 Edge 开发者工具中按 **F8** 或点击“恢复脚本执行”（▶），并检查 Sources 面板的“遇到异常时暂停”是否开启。运行脚本后可以关闭开发者工具，页面脚本仍会继续运行。暂停期间网页和自动脚本都不会继续执行，延长等待时间也无效。控制台的 `work-css-tpl.cssx 404`、`highlight.js deprecated`、`JQMIGRATE` 是学习通页面资源或库的提示，不能单凭这些判断自动脚本失败；请查看是否还有“切换下一学习步骤失败”或“章节测验自动作答停止”的具体错误。

如果控制台显示 `Uncaught SyntaxError: missing ) after argument list`，通常表示粘贴内容被截断或混入了别的文字。请从解压后的 JS 文件用 Ctrl+A、Ctrl+C 重新复制，粘贴后先检查控制台输入末尾是否为 `})();`，再按 Enter。
