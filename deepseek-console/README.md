# 学习通视频与章节测验助手（Edge 扩展 / 控制台双模式）

自动播放学习通课程视频、识别章节测验、调用 DeepSeek 作答并自动提交，然后进入下一节。

**本仓库不含任何 API Key。** 首次使用需要你自己提供 DeepSeek API Key。

> **没有 API Key 也能用。**
> 不配置本地服务时，脚本进入**基础模式**：自动播放视频、自动静音保活、自动点“下一节”；
> 遇到章节测验会停下并把控制权交回你，**不会尝试作答、也不会误点提交**。
> 想要自动答题再按下面的步骤配置服务。

---

## 一、一次性准备

### 1. Node.js

需要 Node.js **18 或更新**（脚本用到 `fetch`、`AbortSignal.timeout`）。

### 2. DeepSeek API Key

两种填法，任选其一：

**方式 A（推荐）：存进环境变量，以后不再输入**

```bat
setx DEEPSEEK_API_KEY sk-你的密钥
```

执行后需要**重新打开**终端窗口才生效。

**方式 B：每次启动时手动粘贴**

不设环境变量，启动脚本后会提示粘贴。输入过程不回显。

> API Key 只保存在服务进程内存里，**不会写入任何文件**，也不会出现在控制台脚本中。

### 3. 中文 OCR 语言包（字体反爬必需）

学习通会把题干里部分汉字替换成生僻字，再用内嵌字体把它们渲染回正确字形（字体反爬）。DOM 里拿到的是替换后的乱码，肉眼看到的是正常文字。

本项目的处理方式是：把文字按页面字体渲染成图片，交给 **Windows 自带 OCR** 还原。因此需要系统已安装中文 OCR 语言包：

- Windows 设置 → 时间和语言 → 语言 → 中文(简体) → 语言功能里确认“光学字符识别”已安装
- 验证：`tools\win-ocr.ps1` 能正常跑出结果即可

Windows 10/11 中文系统通常默认可用（识别语言 `zh-Hans-CN`）。

## 二、启动本地服务

双击 **`启动 DeepSeek 本地服务.cmd`**，窗口会打印：

```
本地服务已启动：http://127.0.0.1:37841
令牌：3f9a...（已复制到剪贴板）
```

- 这个窗口必须一直开着，关闭即停止服务。
- 令牌保存在同目录 `.dsh-token`，**下次启动复用同一令牌**，扩展只需配置一次。
- 令牌同时会写进 `xuexitong-console.js`，所以控制台模式也不需要手动改文件。

想强制换令牌：删掉 `.dsh-token`，重启服务，扩展里重新粘贴一次。

## 三、用法一：Edge 扩展（推荐，免粘贴）

1. 地址栏打开 `edge://extensions`，打开**开发人员模式**
2. 点**加载解压缩的扩展**，选择本目录下的 `edge-extension` 文件夹
3. 点工具栏的扩展图标，粘贴令牌（已在剪贴板里，直接 Ctrl+V），点**保存**
4. 打开学习通课程播放页，脚本自动开始工作

整页跳转由浏览器自动重新注入，不需要辅助弹窗，也不需要每次重新粘贴。

> 要求 Edge 111+（`world: "MAIN"` 注入方式）。
> 扩展是可选的；不装扩展也能用下面的控制台模式。

---

## 四、用法二：控制台粘贴

1. 用记事本打开 `xuexitong-console.js`，全选复制
2. Edge 打开课程播放页，F12 → Console，粘贴，回车
3. 会弹出一个小的辅助窗口，保持它打开（整页跳转后由它重新注入脚本）

> ⚠️ 学习通有 `debugger` 反调试，**按 F12 会让页面暂停**。如果出现“已在调试程序中暂停”，
> 在开发者工具里按 **F8** 恢复。所以状态确认请用**页面左下角的悬浮窗**，不要依赖控制台。

悬浮窗提供：当前步骤、识别到的题量、服务连接状态、最近 6 条日志，以及右上角的**开/关**按钮（随时暂停或恢复）。标题栏可拖动。

## 五、自动流程

- **视频页**：保持页面默认播放速度，全程静音；卡顿时自动恢复播放；结束后点“下一节”
- **基础模式（未连接本地服务）**：只做视频部分。遇到章节测验立刻停止，悬浮窗显示“遇到测验，已暂停”，控制台说明原因——不会提交任何东西
- **测验页**：滚动题目区域 → 识别单选/多选/判断 → 题干与加密选项经 OCR 还原 → 一次性请求 DeepSeek → 逐题点选并二次确认 → 核对题量与“题量：N” → 提交 → 处理二次确认 → 最多等 10 秒捕捉完成标记 → 点“下一节”
- 课程走到最后一节且找不到“下一节”时，打印“本课程学习完成了”并停止
- 模型输出被截断时自动加大额度重试一次；仍不完整则停止，**绝不提交残缺答案**
- 任何环节与预期不符（题量不符、选项不存在、提交被拒）都**停止并写明原因**，不会盲点

调试入口（页面悬浮窗不需要时可用控制台）：

```js
app.inspectQuiz()   // 查看当前识别到的题目
app.diag()          // 查看步骤判定的依据（iframe 清单、页签文字等）
app.nextUnit()      // 手动前进一节
app.dump()          // 把第一题的 DOM 结构写进 debug.log
```

## 七、安全与隐私

- **API Key 不落盘**：仅在服务进程内存中
- **令牌落盘**：`.dsh-token`，因为它需要长期稳定，否则每次都要重新配置
- 服务只监听 `127.0.0.1`，局域网访问不到
- 来源白名单：只接受 `*.chaoxing.com` 与 `chrome-extension://<32位ID>`
- 所有请求都要令牌，令牌不符返回 403
- 题目原文会发送到 DeepSeek API，会产生费用；模型也可能答错

## 九、已知限制

- 只支持学习通 `mooc1/mooc2` 课程播放页（`/mycourse/studentstudy`）
- 依赖学习通当前 DOM：`#coursetree`、`.posCatalog_select`、`.prev_title`、
  `iframe[src*="/knowledge/cards"]`、`.font-cxsecret` 等，平台改版会失效
- 学习内容所在的 iframe 必须与主页面同源，跨域时读不到
- OCR 无法保证 100% 准确，形近字（己/已、未/末）可能出错；日志里保留了每次 OCR 的原文
- 字体反爬的映射每页都会变，因此不做任何映射表缓存，一律用 OCR 还原
- 仅供个人学习流程辅助，使用风险由使用者自行承担
