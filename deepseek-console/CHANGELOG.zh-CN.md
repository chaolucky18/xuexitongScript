# 变更说明（相对原始版本）

本文档说明本分支相对原作者版本做了什么，方便 review。

分三类：**修复**（原实现存在缺陷）、**新增**（原实现没有的能力）、**重构**（行为等价但更可维护）。

---

## 一、修复

### 1. 「输出被截断自动重试一次」从未生效

`deepseek-request.mjs` 的 `ATTEMPTS` 数组只有一个元素，`if (index + 1 < ATTEMPTS.length)` 永远为假。
实测：请求被截断后只发出 1 次 HTTP 调用，却向用户提示“重试后仍未获得完整答案”。

现在：第一档 `max_tokens: 12000`，第二档 `20000`，第二次确实会发出。

### 2. 提交后等待无上限

等待“本次成绩”的循环没有超时，页面改版后会永久空转。
现在：最多等 10 秒，未捕捉到完成标记就直接进入下一节（成绩页往往一闪而过，继续等没有意义）。

### 3. 空 iframe 导致崩溃

`createTreeWalker(doc.body)` 在 iframe 尚未解析完成时抛 `TypeError`，
用户只看到“章节测验自动作答停止”，无法定位。
现在：跳过没有 `body` 的文档。

### 4. 题干被正则截断

原正则 `A\s*(?:[.、．]|\S)` 会把任何以 A 开头的正文行当成选项行，
多行题干的第二行起被吞掉。
现在：优先匹配“行首 A + 分隔标点”，宽松匹配还要求后面确实存在 B 行。

### 5. 选项确认误判

点击后只等 150ms，异步渲染的选项会被判成“未选中”从而中止。
现在：轮询最多 2 秒，并额外认 `checked` / `aria-checked` / class 变化。

### 6. 令牌写回失败直接退出

`writeFileSync` 抛错会结束进程，用户观感是“启动了又闪退”。
现在：降级为提示；令牌持久化到 `.dsh-token`，不再每次改写脚本。

### 7. 页面交互被破坏

原实现拦截并 `stopPropagation` 掉 document 层的 `mouseleave` / `mouseout`，
会连播放器控件、下拉菜单一起失灵，且对同目标监听器其实无效。
现在：不拦事件，只在窗口失焦 / 切后台时恢复播放。

### 8. 章节判定优先级错误

原实现只认 `iframe[src*="/knowledge/cards"]` 的 `num` 参数。
实测该参数会滞后：页面已切到章节测验，`src` 仍是 `num=0`，于是被判成“视频”。

现在按可信度排序：

```
可见的加密/测验内容 → .prev_title 页签文字 → cards 帧 num → 内容兜底
```

### 9. 一次性判断、失败即永久停止

`play()` 认不出当前步骤就打印“已安全停止”然后结束，页面之后加载好也不会再醒。
现在：认不出时等待 20 秒轮询重判，再决定是否放弃。

## 二、新增

### 1. 字体反爬的 OCR 还原（本版本核心）

学习通把题干里的部分汉字替换成生僻字，再用内嵌的 `font-cxsecret` 字体渲染回正确字形。
DOM 里是替换后的乱码，只有“渲染出来的形状”是对的。

实测数据：某个 cards 帧 `innerText` 只有 1 个字符，`textContent` 有 13453 个字符；
加密后的题干形如 `职业慥涯慧划慨三慡核慩要慦慠()`，真值是 `职业生涯规划有三个核心要素是()`。

尝试过但放弃的方案：解析加密字体做映射表。
发现字形是 Source Han Sans 子集（`post` 3.0，字形名被抹除），且**映射每页都会变**
——上一页的密文字与本页完全不重叠，硬编码表只能救一页，且过期表会“静默翻译”出通顺但错误的文字。

最终方案：

```
题干文字 ──按页面字体渲染到 canvas──▶ PNG ──▶ Windows.Media.Ocr ──▶ 真文字
```

读的是字形，与字符码、映射表、字体怎么换都无关。
- 服务新增 `POST /ocr`，调用 `tools/win-ocr.ps1`（`Windows.Media.Ocr`，约 0.9–1.3 秒/张）
- 题干逐题还原；只有确实带 `.font-cxsecret` 的选项才额外 OCR
- OCR 失败时退回原文，并把字体存到 `dump/` 便于事后排查
- 需要系统装中文 OCR 语言包（Windows 中文系统默认具备）

### 2. 页面内悬浮状态窗

学习通有 `debugger` 反调试，一按 F12 页面就全局暂停，控制台没法用来确认状态。
所以新增左下角悬浮窗：当前步骤、识别题量、服务连接状态、最近 6 条日志，
右上角有**开/关**按钮可随时暂停/恢复，标题栏可拖动，支持折叠、自动避让窗口边界。

### 3. Edge MV3 扩展（可选）

解决两个痛点：每次都要粘贴 1000+ 行脚本；整页跳转后脚本消失。
- `world: "MAIN"` 注入，复用页面自带 jQuery，业务逻辑零改动
- 三层结构：主世界 → `bridge.js` → `background.js`
  后台是唯一能自由访问 `127.0.0.1` 的上下文，因此**不再触发 CORS / Private Network Access 弹窗**
- 整页跳转由浏览器自动重新注入，原来的辅助弹窗 hack 在扩展模式下完全不需要
- 令牌只需配置一次（持久化在 `.dsh-token`）

### 4. 运行日志落盘

页面脚本把 `console.*` 全量镜像、`window.onerror`、`unhandledrejection`
以及关键状态（启动快照、iframe 清单、判定结果、OCR 结果）写入 `debug.log`，
排查不需要 DevTools。

### 5. 基础模式：不配置服务也能刷视频

原实现开头就检查令牌，没有令牌直接 `return` —— 连视频都不播。
现在去掉这个硬性中断：连不上本地服务时进入**基础模式**：

- 视频部分完全照常：静音、卡顿保活、播完点下一节、整页跳转后重新注入
- 遇到章节测验**停下并说明原因**，不尝试作答、不提交
- 悬浮窗显示“基础模式：仅自动刷视频”，服务行显示“未连接（基础模式）”

只想刷视频、或暂时没有 API Key 的人也能直接用。

### 6. 其它

- 支持 `DEEPSEEK_API_KEY` 环境变量（免每次输入）、`DEEPSEEK_MODEL`、`DEEPSEEK_API_URL`、`XUEXITONG_PORT`
- 端口占用时给出明确提示而不是堆栈
- 课程走到末尾时正常收尾（原来会抛“未找到下一节”）
- 推理档位由 `reasoning_effort: 'low'` 提高到 `'high'`

## 三、重构

- 删除约 100 行死代码：`nextUnit` / `playCurrentIndex` / 旧 `_advanceChapterTest` 被后续实现覆盖，从未执行
- `courseDocuments()` 抽到顶层复用，新增 `documentText()` / `textOf()` 统一文本抽取
- 新增 `tools/selftest.mjs`（24 项，mock 掉 API）与 `edge-extension/tools/bridge-test.mjs`（14 项），
  覆盖令牌、Origin 白名单、截断重试、题目校验、题干切分、桥接链路

## 四、行为变化（可能影响使用习惯）

| 项目 | 原行为 | 现在 |
| --- | --- | --- |
| 令牌 | 每次启动轮换，需重新复制脚本 | 持久化，配置一次 |
| 提交后 | 无限等成绩页 | 最多 10 秒，然后进下一节 |
| 认不出步骤 | 立即停止 | 等 20 秒再判 |
| 页面 event | 拦截 mouseleave/mouseout | 不拦 |
| 题干还原 | 提示词让模型猜 | 渲染成图后 OCR |
| 没有令牌 / 连不上服务 | 直接 `return`，什么都不做 | 进入基础模式，只刷视频 |

## 五、验证情况

已验证：

- 全部 13 个 JS/MJS 文件语法通过
- `tools/selftest.mjs` 24 项通过（令牌生成与复用、Origin 白名单、截断重试、题目格式校验、题干切分）
- `bridge-test.mjs` 14 项通过（主世界 → 桥 → 后台 → 本地服务 全链路）
- 真实 DeepSeek API 连通（返回 200 与正确答案）
- Windows OCR 端到端通过（识别 70 个加密字形，与人工辨认逐字一致）
- 实际课程页跑通：视频播放 → 章节测验识别 → 作答 → 提交 → 下一节

**未验证 / 需要使用者自行确认：**

- 不同学校、不同学习通版本（`mooc1` / `mooc2`）的页面结构差异
- OCR 对形近字的准确率，未做逐字置信度校验
- Edge 111 以下的兼容性（扩展依赖 `world: "MAIN"`）
