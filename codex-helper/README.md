# Codex 油猴章节练习助手

独立可选入口：正常播放课程视频，结束后进入章节测验，通过本机已登录的 Codex CLI 识别题目、选择并提交答案，看到实际成绩后再进入下一节。现有 V3 与 DeepSeek 入口保持各自用途，使用本版时请停用其他同时操作该课程页的脚本。

## 环境与安装

- Node.js 20 或更新版本，无需 `npm install`。
- 安装 Codex CLI，执行 `codex login` 并用 `codex login status` 确认已经登录。本版使用 `codex exec`、`--image`、`--output-schema`、`--ephemeral` 等参数，需要支持这些参数的 Codex 版本。
- 浏览器安装 Tampermonkey，并允许用户脚本运行。

1. 将整个 `codex-helper` 目录保存在本机。Windows 双击 `start.cmd`；其他系统运行 `node codex-helper/start.mjs`。
2. 首次启动会生成本机配置 `bridge-settings.json` 和 **`codex-helper.user.js`**。将生成的 `.user.js` 导入油猴；**不要安装 `codex-helper.template.user.js`**。
3. 停用其他课程自动操作脚本，打开课程的学生学习播放页并刷新。左下角“Codex 学习助手”会显示连接、作答或停止原因。
4. 保持本机服务窗口打开。视频选择平台原生菜单提供的最高倍速，结束后依次处理章节测验、确认成绩、进入下一节。

Windows 优先识别 Codex 桌面应用附带的 `codex.exe`，也支持 PATH 中的原生 CLI 和 npm 安装入口。特殊安装位置可通过 `CODEX_QUIZ_EXECUTABLE` 指定 `codex.exe` 或 `codex.js`。

不需要把 API Key 填到油猴脚本中。Codex CLI 自行复用其已保存的登录状态，调用使用当前账户的可用额度。实现依据：[OpenAI 官方非交互模式文档](https://learn.chatgpt.com/docs/non-interactive-mode)。

## 同一页面多视频衔接

同一章节页面包含多个原生视频附件时，按页面顺序选择尚未完成的视频，优先级不再被第一个已加载、已完成的视频占用。尚未加载的下一个视频通过自身原生播放按钮初始化一次；全部视频完成后再进入文档或章节测验。非原生的空播放器仍使用原有筛选规则，避免错误接管无关媒体。

## 视频弹题纠错

平台明确显示“回答错误”且原生提交按钮可用时，将失败选项作为反馈附在题目图片中重新判断，修改选项并再次提交；不复用被拒绝的答案，每题最多三次不同答案提交。记录失败选项供刷新后恢复判断。结果不明、平台要求回看、答案不确定或重复失败答案时停止，不自动枚举答案。仍只读取可见题目和正常选中状态，不读取隐藏评分值。

## 已完成视频识别修复

重新进入章节时，优先识别当前视频所在附件的原生 `ans-job-finished` 完成标记，停止重复播放并通过既有衔接流程进入未完成文档或测验。没有完成标记的内容仍按正常流程处理；读取不到框架时不推断完成。不修改平台任务记录。

## 4.4.0 更新

- 可拖动、折叠并记住位置的状态面板，显示播放进度、剩余任务和连接状态；双击标题复位。
- 实际播放进度监测、有限次数恢复、原生备用线路切换，播放器时间回退后重新建立监测基准。
- 视频结束事件遗漏时，在结束且无任务处理的状态持续 6 秒后恢复下一步骤；45 秒仍无响应则提示，避免无限点击。
- PDF/PPT 阅读与章节测验衔接、视频内弹题、随机排列选项映射及精确选中校验。
- 整门课程明确完成后，按列表顺序继续有未完成进度的课程，跳过显示 100% 或任务全部完成的课程。无进度信息的课程不自动进入。
- 异步监测防重入、停止/重启后的旧回调隔离和唤醒锁竞态保护。
- 本机桥接支持会话健康检查与每会话限制；更新时须同时更新桥接文件与生成的油猴文件。普通启动仍需保持服务运行，不自动安装系统启动项。

上述功能不修改平台学习时长或任务点。真实平台全课程、多课程长时间运行仍需持续验证；模型不确定、无法确认提交结果等情况会停止。

## 改进内容

- **题目实际字形识别**：学习通复制出的文字可能经过字体替换；使用题目所在文档的已加载字体，在 Canvas 上逐段绘制题干与选项，再将图片交给 Codex，不依赖模型猜乱码。备用字体加载失败不会阻断已经可用的题目字体；题目关键字体缺失会停止。
- **接管当前播放器**：扫描可访问 iframe，跳过跨域框架、隐藏框架和旧文档中的视频，优先选择真正加载的播放器；播放器更换后重新绑定事件，忽略旧播放器的结束事件。
- **完整章节流程**：视频结束进入章节测验；支持单选、多选、判断，核对题量和答案格式；选中后读取平台实际选中值，兼容判断题的 true/false，并避免重复点击把多选选项取消。
- **确认实际结果**：目录完成图标或满分说明不作为提交成功证据。只有检测到实际成绩和已提交答案才继续；提交结果未确认时保留记录，防止刷新后盲目重复提交。
- **停止与边界**：识别不确定、图片题、未支持题型、题量不符、页面变化或请求失败会停止并说明原因。仅在课程播放页的普通章节测验流程操作，不接管考试页面，不修改学习时长或任务点记录。

模型可能答错，成绩以平台实际显示为准。若课程要求前台观看、不可最小化，请按页面要求保持前台，不让电脑休眠。

## 本机服务与隐私

- 仅监听 `127.0.0.1`，默认端口 `37843`；首次启动生成随机连接令牌，并写入本机生成的油猴文件。
- 配置、含本机令牌的生成文件、进程信息和运行日志均已加入本目录 `.gitignore`，不应提交或分享。
- 题目图片、题型和选项会通过本机服务发送至 Codex；账户登录令牌由 CLI 自行管理，不读取或复制到网页。
- 子进程关闭命令执行、多代理、插件及联网搜索，使用只读沙箱、临时会话和 JSON Schema；题目内容不作为工具指令执行。
- 同时只处理一套题，每个答题会话最长 12 小时、最多 150 次模型调用；超时或不确定答案不继续提交。相同请求可复用本次服务内的缓存。
- 临时题目图片在调用后清理；`bridge-events.jsonl` 记录调用状态及已观察到的章节成绩，不保存账户凭据。

启动入口会运行独立后台守护：每 10 秒健康检查，连续 3 次失败后尝试重新启动；10 分钟最多 5 次重启，避免重启风暴。主动停止会留下停止标记，守护不会重新拉起。改动端口或重新生成连接令牌后，要重新生成并在油猴中更新脚本。

## 停止

面板的 **停止** 按钮会停止本页操作并暂停课程队列，刷新后保留停止状态；点击 **继续** 恢复。长期停用可在油猴中禁用脚本。

Windows 双击 `stop.cmd`，其他系统运行 `node codex-helper/stop.mjs`，可以停止本机服务和正在进行的 Codex 调用。停止服务不等于禁用网页脚本，网页上也请停止助手。

## 4.4.1 稳定性更新

- 本机服务异常退出可自动恢复，已有健康服务不被打断，重复启动不会多开守护。启动窗口需保持打开；Windows 本地后台入口可隐藏运行。
- 网页断线后每 5 秒重连，正常连接时每 30 秒检查；停止后旧请求不能恢复定时器。
- 视频结束后下一步骤加载超时，先按原有冷却时间与次数上限重新加载；不会无限刷新，也不会跳过测验。
- `watchdog-status.json` 保存最近健康检查和重启次数，内容不含令牌；`stop.cmd` 同时关闭恢复机制。
- 已验证独立子进程崩溃恢复、重复守护互斥、主动停止、重启限流、网页重连和结束衔接恢复上限。


### 4.4.2：首次不确定后的单题复核

整套识别返回“不确定”后，重新渲染每道可见题目并分别识别，每题最多复核两次。所有题目的答案都通过原有置信度与格式校验后才进入选项填写和提交。不会强行提高置信度；停止、页面变化、其他错误或复核仍不确定时保留待处理状态，不循环提交。单题复核会增加模型调用次数，仍受会话总次数限制。


### 4.4.3：额度等待与临时故障恢复

本地桥接区分额度限制、登录失效和临时网络错误，并将错误类型与下次重试时间返回网页。额度不足时按服务提示的本机时间等候；没有可解析时间则等候 15 分钟，再检查，最多三次。桥接在等待期内不启动新的模型进程。网络故障最多重试三次。等待保留当前题目、唤醒与手动停止功能；题目变化、会话结束或用户停止会取消后续操作。登录失效与未知错误继续提示处理。不会切换账号、购买额度或更换模型。


### 4.4.4：视频弹题人工接管与局部等待

视频弹题等待模型、服务重连或额度恢复期间，检测到人工选择/提交后取消旧答案的操作资格，避免覆盖人工答案或重复提交。自动点击派生的原生事件不会误判为人工接管。

无法识别或作答时保留当前弹题为局部待人工处理，整体监测继续；原生弹题消失且实际播放时间推进后解除阻塞，继续下一任务。提交结果不明、平台要求回看及次数上限仍保留，不会把未知结果当成已完成。该保护不保证所有题型或模型答案都能自动处理。

本次现场观察到本地答题服务离线，已使用现有启动入口恢复；启动快捷方式路径有效，未确认离线的触发原因。浏览器脚本不能在后台进程全部退出时自行启动本机服务。新增人工接管竞态通过可控回归用例验证，不能据此声称所有真实弹题均已验证。

人工接管记录保留此前提交选项、拒绝历史和原始状态；刷新或重建控制器后仍优先尊重人工接管、三次上限、提交不明和回看约束。


### 4.4.5：章节播放器网络错误恢复

可见且属于当前页面的原生视频即使带有媒体错误也保留在监测快照中，避免网络错误被误判为没有播放器。章节引擎遇到网络错误 2 时，先使用播放器已标识的备用公网线路；35 秒内不重复切换，只有清除错误且播放时间实际推进才确认恢复。超时回落到已有每视频 2 次、每会话 6 次、120 秒冷却的有限页面恢复。

线路历史使用课程、会话、章节和原生附件标识（无标识时用附件顺序）持久化，不依赖会切换的 CDN 地址、路径或签名参数。其他媒体错误、未知当前线路或无备用线路时不猜测。视频弹题、人工接管及其他学习步骤优先处理，期间不切换线路或刷新；停止会清理待恢复状态。

本轮真实故障在安装前由人工刷新恢复；新故障选择路径与章节自动换线使用实际生成代码的集成回归验证，现场安装后仅验证持续正常播放，不能把人工恢复记为新版自动故障恢复。

计时器迟到时先确认视频是否已经清错并恢复真实播放，再判断未恢复的超时；避免后台定时器节流造成不必要刷新。


### 4.5.0：专题门户正文逐屏浏览

支持 `/mooc-ans/zt/portal/` 专题页的独立阅读入口，提前绕开普通课程队列、播放器与 Codex。只识别已显示的正文 DIV 和原生目录顺序，不读取重复 ID 的 SCRIPT、隐藏配置或私密参数。使用真实 BODY 滚动区域，每屏重叠 25%，视口图片就绪且布局稳定后前台停留至少 12 秒。

开始/继续、暂停、停止和专题独立断点均在页面面板中；隐藏或失焦时停止滚动、点击及自身停留累计，返回后不补算后台时间。正文未加载时只点击原生加载更多，每次等待真实追加再继续；失败或跨目录内容会停止提示。刷新恢复较深断点时逐次原生加载已浏览前缀，不把新加载内容自动算作已浏览。

“本节已浏览”只代表助手已逐屏展示，不代表理解内容、平台计时认可或平台任务点完成。不会修改平台计时、窗口检测或完成标记，也不转发、收藏、答题或自动转向其他专题。首次进入新专题默认等待开始；只有此前明确启动的同一专题可以恢复其启用状态。


### 4.5.1：真实倍速反馈与单次标准 2x 请求

- 优先选择原生菜单最高倍速；原生选项不可用或未生效时，对当前视频仅请求一次标准 `playbackRate=2`。
- 显示目标和实际倍率。平台回退或拒绝时显示“页面限制”，同一视频不会反复强制设置；换到不同视频后可重新尝试一次。
- 不跳转播放时间，不改视频时长、学校配置、学习计时或任务完成记录。实际播放倍率不保证服务端学时按同一比例增加。
