# DeepSeek 油猴联动版（Mac / Chrome）

这是可选入口，基于仓库的 V3 播放器生成独立油猴脚本，默认 1 倍速。它面向带有独立“视频 / 章节测验”页签的章节练习页。

视频结束后先点击当前小节的“章节测验”，等待题目加载；识别单选、多选、判断题并通过本机服务请求 DeepSeek。提交前校验题量、答案格式与页面选中状态，平台显示成绩后才进入下一小节。跨分组时只选择实际小节，跳过分组标题。跳转固定同一个目录目标，每 8 秒检查一次，最多点击 3 次；抵达后等待新视频加载并启动播放。停止脚本或手动离开目标会取消重试。

视频出现“无法播放媒体”、网络错误或解码错误时，脚本会按页面提供的顺序尝试下一个未禁用线路，优先调用播放器原生 `selectCDN`；接口不可用时才根据清晰度原始地址生成备用 URL。每条线路等待 12 秒且只尝试一次，成功后保留原有播放位置。学校线路的 HTTP 地址会自动提升为 HTTPS，避免 Chrome 拦截不安全媒体。

答题请求默认关闭长篇思考输出，只要求返回紧凑的答案 JSON。若 DeepSeek 仍返回 `finish_reason=length`，脚本会把当前题目自动拆成更小的批次继续请求并合并答案，避免生成数千 tokens 的推理后仍没有完整结果。

若提前手动进入测验，完成后返回当前视频，等视频结束再换节；不会因为测验提前完成而跳过当前视频。当前版本不处理填空、简答、考试及不认识的课件页面。模型答案可能有误，“校验”仅指格式和选中状态，并不保证正确率。

## 安装与使用

需要 Node.js 26（测试依赖也支持 22.22.2+ 的 22 系列和 24.15+ 的 24 系列）、Chrome 和官方扩展商店安装的 Tampermonkey。

```sh
cd deepseek-userscript
npm install
npm run build
npm start
```

1. 保持服务终端打开，访问 `http://127.0.0.1:37841/`，自行输入 DeepSeek 官方开放平台 API Key 并验证。网页账号或会员不能代替 API Key。
2. 在 Tampermonkey“实用工具 → 导入”选择 `dist/学习通-DeepSeek.user.js`。Chrome 扩展详情中开启用户脚本运行，允许扩展访问课程网站；如课程页提示访问本机网络，选择允许。
3. 禁用其他自动学习脚本，刷新课程页。右下角显示助手及连接状态后开始使用。不要与原 V3、控制台版同时运行。
4. “自动识题作答”默认开启；“答案校验后自动提交”默认开启，可取消勾选改为人工检查、人工提交，提交偏好会保存在该浏览器。
5. 点击“停止脚本”会暂停播放、隐藏助手、停止识题和待执行跳转；右下角“启动脚本”可恢复。禁用油猴脚本后需刷新课程页，才能清除已经注入的页面代码。

Mac 也可双击生成的 `dist/启动 DeepSeek.command` 启动服务。关闭服务后，下次使用需要重新输入 API Key。

## 本机文件与数据

- 构建产物在 `dist/`，其中随机 `.service-token` 与配套油猴脚本成对使用。再次构建会保留此令牌；不要分享生成目录。它们已经被 Git 忽略。
- API Key 仅保存在服务内存，不写入脚本或文件，也不会返回课程页。服务仅监听 `127.0.0.1:37841`，检查来源、连接令牌和配置表单来源。
- 题干、选项会发送给 DeepSeek 官方 API，可能产生费用。相同题目的成功结果缓存 10 分钟，服务关闭后清除。
- 本机服务不是浏览器插件；只需自动播放时，无须配置 DeepSeek。若处于章节测验，未连接服务会停留等待，不会直接跳过测验。

## 常见停留情况

- **本机服务未连接**：先检查服务终端是否仍在运行，再检查课程页的本机网络许可。不要同时启动多份服务占用同一端口。
- **测验加载超时 / 无法识题**：停留在当前小节，人工检查页面，不自动跳过。
- **视频提示无法播放媒体**：脚本会尝试切换到公网2、本校等未禁用线路；全部线路失败后停止重复尝试并显示提示。
- **DeepSeek 输出达到长度上限**：脚本会自动拆分题目重新请求；单题仍截断时停止填答并提示，不会提交不完整答案。
- **测验完成但下一节未打开**：脚本会检查 URL 是否真的变化，重试同一目标；三次无响应后显示提示，请处理平台弹窗或手动选择下一节。
- **下一节已打开但视频未启动**：最多等待 120 秒，并在视频出现后尝试启动；超时提示后可检查页面并重新启动脚本。

## 验证

```sh
npm test
node ../tests/verify-v3.mjs
```

测试只使用模拟题和伪造 API，不消耗真实 DeepSeek 额度。覆盖紧凑答案请求、长度截断后分批、题目提取和填选、提交确认、章节隔离、停止和重启、异步播放竞态、媒体错误后线路轮换，旧 iframe 视频缓存失效后重新定位和重绑结束事件，以及构建产物的“视频结束 → 延迟测验 → 作答提交 → 成绩 → 下一小节”流程。另有首次导航点击无响应、重试同一目标及目标视频恢复的回归场景。

真实 Mac / Chrome 章节页已验证基础闭环；不同学校页面结构或平台更新仍可能需要适配。
